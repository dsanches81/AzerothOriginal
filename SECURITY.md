# Segurança

O Azeroth Original é um addon de interface: roda só dentro do World of Warcraft, não acessa a internet, não lê nem envia dados pessoais e não automatiza nenhuma ação do jogo.

Os pacotes publicados no CurseForge e nas Releases do GitHub são gerados automaticamente a partir deste repositório pelo GitHub Actions (BigWigs Packager), a cada tag de versão. Baixe sempre por esses dois canais.

## Como reportar um problema de segurança

Se você encontrar algo que pareça um problema de segurança, **não abra uma issue pública**. Use a aba **Security → Report a vulnerability** deste repositório para enviar um relato privado.
